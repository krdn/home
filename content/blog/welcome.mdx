# KRDN 홈페이지를 소개합니다

안녕하세요! KRDN의 새로운 홈페이지를 공개하게 되어 기쁩니다.

## KRDN이란?

KRDN은 **AI 기반 자동화 솔루션**을 개발하는 회사입니다. 우리는 Claude, GPT 등 최신 AI 기술을 활용하여 업무 자동화, 워크플로우 최적화, 지능형 에이전트 개발에 집중하고 있습니다.

## 우리의 비전

> "AI로 자동화를 혁신하다"

복잡한 반복 작업을 자동화하고, 인간이 더 창의적인 일에 집중할 수 있도록 돕는 것이 우리의 목표입니다.

## 주요 서비스

1. **Gonsai2** - n8n 워크플로우 최적화 플랫폼
2. **News Sentiment Analyzer** - AI 기반 뉴스 감정 분석
3. **Claude Code Auto** - AI Orchestrator Framework
4. **n8n Agent Generator** - 자동 워크플로우 생성 도구

## 앞으로의 계획

- 더 많은 AI 기반 서비스 출시
- 오픈소스 프로젝트 확대
- 기술 블로그를 통한 지식 공유

앞으로도 많은 관심 부탁드립니다!
