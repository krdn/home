# Gonsai2: n8n 워크플로우 최적화 플랫폼

Gonsai2는 n8n 워크플로우를 위한 AI 기반 최적화 플랫폼입니다. 복잡한 워크플로우를 시각화하고, 성능을 분석하며, 개선점을 제안합니다.

## 주요 기능

### 1. 워크플로우 시각화

n8n 워크플로우를 직관적인 대시보드로 시각화합니다.

- 노드 간 연결 관계 파악
- 실행 흐름 추적
- 병목 지점 식별

### 2. 실시간 모니터링

워크플로우 실행 상태를 실시간으로 모니터링합니다.

- 실행 성공/실패 현황
- 평균 실행 시간
- 에러 로그 분석

### 3. AI 기반 최적화 제안

Claude API를 활용하여 워크플로우 개선점을 자동으로 분석합니다.

- 불필요한 노드 제거 제안
- 병렬 처리 가능 구간 식별
- 에러 처리 개선 권장

## 시작하기

### 설치

```bash
git clone https://github.com/krdn/gonsai2
cd gonsai2
docker-compose up -d
```

### 연결 설정

1. Gonsai2 대시보드 접속 (https://gonsai.krdn.kr)
2. n8n 인스턴스 URL 입력
3. API 키 설정

## 기술 스택

- **Frontend**: Next.js, React, TypeScript
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **AI**: Claude API
- **Deployment**: Docker, Nginx
